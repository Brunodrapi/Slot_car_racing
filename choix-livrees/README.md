# Choix des livrées GT3 — recette

Page autonome de sélection : sept références photographiques pour chacun des dix modèles,
trois choix maximum par modèle. Les 70 photos sont servies depuis `photos/` sans dépendre
des sites externes. Chaque carte conserve son lien source, son crédit et son contexte.

Adresse de recette : https://brunodrapi.github.io/Slot_car_racing/choix-livrees/

Les sélections restent dans le navigateur (`grip.gt3.livery-research.v1`). Le bouton
« Copier mes choix » prépare le récapitulatif à coller dans le chat ; rien n’est envoyé
automatiquement. Les références RSR transposées sur la Porsche GT3 R sont signalées.

La page se joue telle quelle : aucun build ni déploiement de fonctions n’est nécessaire.
Elle est exclue de la distribution du jeu par la liste explicite de `tools/build-dist.js`.
