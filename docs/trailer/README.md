## Ce que contient cette première version

1280 × 720, H.264, 24 images/seconde, musique AAC. Les douze cases de la mosaïque sont capturées à 12 images/seconde et assemblées à 24. Les interfaces sont en anglais, les textes du script sont conservés.

Les pilotes sont automatisés ; les positions/vitesses initiales des accidents sont préparées, puis la physique réelle tourne. Les caméras spectateur sont celles du jeu, mais la course est locale : ce n'est pas l'enregistrement d'une session Internet. Les menus de catégories sont trois prises fixes successives, pas une navigation manuelle filmée. La caméra suit les voitures avec un cadrage de tournage.

Les titres et leur durée sont modifiables. La version fournie utilise « Rhinoceros » de Kevin MacLeod, sous CC BY 4.0 ; le crédit apparaît au carton final et doit être conservé dans la description de publication. Aucun son moteur n'est enregistré dans cette première version. Les coupes suivent le script temporel et ne sont pas toutes synchronisées sur les temps musicaux.

Le dossier local de sortie contient également le montage silencieux, les huit sections séparées et le rapport des captures. L'archive des prises conserve les images/MP4 sans titres, le script, les crédits et le rapport pour reprendre le montage dans un éditeur vidéo.
